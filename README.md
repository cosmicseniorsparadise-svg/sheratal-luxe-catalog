# SHERATAL Luxe Catalog

Build a premium, elegant e-commerce catalog website for SHERATAL, a luxury women's fashion brand based in Dwarka, New Delhi. Color palette: white, gold, and black — editorial, high-fashion, boutique feel (generous whitespace, gold accents/dividers, serif headings paired with a clean sans-serif body font).

Pages/sections:

Hero section with brand logo/name, tagline, and a striking full-width lookbook-style image
Shop/Catalog page showing all product categories in a clean grid — product image, name, price, sizes (up to 5XL). Product data/images should be structured so they can be pulled in from our Instagram feed (@sheratal_) content
Product detail view with image gallery, size selector, and an "Order on WhatsApp" button that opens a pre-filled WhatsApp chat with the product name
Sticky/floating WhatsApp button visible site-wide for quick order enquiries — no login or account system needed, keep ordering to a single WhatsApp tap
About page telling the SHERATAL brand story (luxury, inclusivity, body-positivity)
Showroom/Visit Us section: Sector 7, Dwarka, New Delhi, embedded Google Map, store hours
Footer with Instagram (@sheratal_) and Facebook (sheratals) links, contact info

Fully mobile-responsive, fast-loading, easy to browse. Subtle gold hover animations, smooth scroll transitions for a premium feel.
